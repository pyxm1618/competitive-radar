# Intelligence authority (external-AI file protocol)

This directory is **authoritative and version-controlled**. It is the only
external-AI intelligence store in the repository.

```
data/intelligence/
├── pending/<change_id>.json       deterministic input queue (generated by `radar prepare`)
├── records/<intelligence_id>.json intelligence output (written by Antigravity)
├── research/<request_id>.json     manual research queue
├── weekly/<week_start>.json       derived Weekly Pulse (written by `radar build`)
└── schema/*.schema.json           JSON Schemas generated from pipeline/radar/contracts.py
```

Rules:

1. `pending/` is generated **only** by `radar prepare` from the deterministic
   snapshot diff in upstream `raw.changes`. It contains no AI prose.
2. `records/` is written **only** by the external Antigravity agent following
   `.agents/skills/competitor-intelligence/SKILL.md`. Exactly one record per
   `change_id`.
3. `radar validate` must pass before `radar build`.
4. Raw evidence is **not** copied here. Evidence entries reference upstream
   `raw.raw_pages` snapshot ids, the Parquet landing zone, and
   `evidence/manual/` assets. There is no second raw-evidence database.
5. **The authoritative `records/`, `pending/`, `research/` directories are
   intentionally empty in V1** because the real competitor list and the first
   Antigravity analysis run have not been supplied. Clearly-labelled sample
   fixtures live in `examples/` and are used by `radar demo-build` only.

Do not hand-edit `schema/*.json`; regenerate with `radar contracts`.
